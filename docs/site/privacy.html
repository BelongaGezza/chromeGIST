chromeGIST Privacy Policy

Applies to chromeGIST version 0.1.0 · Effective 25 October 2026

In short: chromeGIST reads only the text you select, only when you ask it to, and only in your browser's memory. It does not collect, store, sell, share or send your data anywhere. It has no accounts, no analytics and no network access.

1. What chromeGIST is

chromeGIST is a Chrome extension that shows text you have selected on a web page one word at a time, at a pace you control (a "speed reader"). You select text, right-click, and choose Speed Read with chromeGIST. A small window then shows the words.

2. What information it receives

Only the text you selected, and only when you choose Speed Read with chromeGIST from the right-click menu. Chrome passes that selection to the extension when you click the menu item.

chromeGIST does not see anything else. It cannot read the rest of the page, other tabs, your browsing history, form fields, the page address or title, or your clipboard. It asks Chrome for a single permission, contextMenus, which is what adds the right-click menu item. It has no access to websites, no content scripts and no storage permission.

3. What it stores

Nothing is saved to disk. There is no library, history, cache, cookie or settings file, and your reading speed is not remembered either.

While you read, the selected text is held in the browser's memory:

  • briefly by the extension's background process, from your click until the reader window picks it up (it is deleted the moment it is picked up, or after 60 seconds if it is not);
  • by the reader window, for as long as that window is open.

When you close the window, the text is discarded. chromeGIST does not overwrite that memory; it simply never writes the text anywhere.

4. What leaves your computer

Nothing. chromeGIST contains no code that sends data to any server, and Chrome is told to block the extension from contacting any other website. All of the reading logic runs locally in your browser. The extension does not load or run code from the internet; everything it runs is in the package you installed.

5. Selling, sharing and third parties

We do not collect your data, so we have none to sell, share or transfer. chromeGIST includes open-source software libraries that run locally inside the extension to split text into words and set the pace; they do not communicate with anyone. Their licences are listed in the extension's THIRD_PARTY_NOTICES.txt.

6. Incognito windows

chromeGIST works in Incognito only if you turn on Allow in Incognito for it in Chrome's extension settings. If you do, text selected in an incognito window is read in the incognito window and is handled the same way: held in memory only and not stored.

7. Things outside chromeGIST's control

  • The page and your system. The website, other extensions that can see that page, screen readers and your operating system's clipboard tools can see your selection independently of chromeGIST.
  • Long selections. Chrome may shorten very long selections (about 7,500 words) before the extension receives them. chromeGIST cannot tell when this happens, so the reader reminds you at the end. This affects completeness only.
  • Crash reports. If Chrome crashes while you are reading, and you have turned on Chrome's option to send usage statistics and crash reports, a report could contain some of the text in memory at the time. This is Chrome's behaviour, not something chromeGIST sends.
  • Memory swapping. Your operating system may move browser memory to disk as it normally does.

8. Children

chromeGIST collects no personal information from anyone, including children.

9. Changes to this policy

If a future version changes what chromeGIST does with data, this page will be updated before that version is released, and the effective date and version above will change. Today's version collects nothing, so any change that begins to collect or send data would be a significant change.

10. Contact

Questions about this policy: open an issue on the chromeGIST GitHub repository
