# Security policy

chromeGIST is a small Chrome extension with one permission (`contextMenus`),
no network access and no storage. See [`docs/SECURITY_REVIEW.md`](./docs/SECURITY_REVIEW.md)
for the review and [`docs/PRIVACY.md`](./docs/PRIVACY.md) for what it does with
your text.

## Reporting a vulnerability

Please report security problems privately, using GitHub's
[private vulnerability reporting](https://github.com/BelongaGezza/chromeGIST/security/advisories/new)
for this repository, rather than opening a public issue. Include the Chrome
version, the extension version and steps to reproduce.

## Supported versions

Only the latest release and `main`.
